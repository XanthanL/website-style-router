# IA：作品集型（Portfolio）

**核心命题**："看我做过什么。"

## 适用条件
- 主体是**作品/项目**而非服务或商品
- 条目数 5–40，每个条目有独立视觉
- 受众是评审、潜在客户、同行——**愿意点进去看**
- 转化目标弱（"联系我"即可，不需要漏斗）

## 区块组成
```
index      →  grids of work（封面网格，非轮播）
work/[id]  →  单件详情：视觉主体 + 3-5 句说明 + 元信息（年份/材料/角色）
about      →  一段自述 + 履历/展历
contact    →  直给邮箱，不要表单
```
常见变体：**case-study 型**（每个项目写决策与取舍，不只是成品图）— 适合设计师/工程师，不适合纯视觉艺术家。

## 典型误用
- 用轮播替代网格 → 用户看不到全貌，且移动端必崩
- 详情页塞满图但不写一句说明 → 变成 Pinterest
- 加"服务/价格/团队"区块 → 那是 conversion 型，混进来会两头不靠

## Token 倾向
- 网格间距大（≥32px），封面之间留足呼吸
- 标题字阶跨度大，正文极简
- **图片是主角 → 容器不要有阴影/圆角/边框抢戏**
- 导航极轻，甚至只有 logo + 一个 about

## 被排除的常见原因
视觉资产质量低（手机随拍、扫描件）→ 封面网格会暴露画质，改走 narrative 或 directory。

## 页面粒度与页内导航（默认，可被内容推翻）

> 阈值与完整判据见 [`granularity.md`](granularity.md)。这里只给本原型的默认倾向。

- **默认粒度**：`master-detail` —— `index`（作品网格）+ `work/[slug]`（单件详情，一个模板生成 N 页）
- **默认页内导航**：`none` —— 索引页是网格，扫读即可；给网格页加目录是噪音
- **判据**：
  - 作品 ≥4 件且每件有独立深度内容（2 张图以上 / 多段说明）→ `master-detail`
  - 作品 ≤3 件或每件只有 1 图 + 1 句话 → 降为 `single`（灯箱足够）
  - 作品 >20 件且带分类 → 升为 `multi-page`（分类页 + 详情页）
- **详情页必须有索引页没有的信息**：元信息（年份 / 材料 / 角色）+ 3–5 句说明 + 全部图。
  **只把封面图放大 = 假子页**，退回 `single`。
- **灯箱与详情页不冲突**：灯箱做快速浏览，详情页做「可分享、可被收录的那一条」。
  但**卡片的主链接必须指向详情页 URL，不是 `#`** —— 否则单件永远无法被单独分享。
