# IA：转化落地页型（Conversion）

**核心命题**："做这一件事。"

## 适用条件
- 有**单一、明确、可数的转化动作**（预约、下单、报名、留资、下载）
- 受众多为陌生流量（广告、搜索、社交引荐）
- 决策成本低或中等，不需要深度教育

## 区块组成
```
  01 Hero：一句话价值主张 + 主 CTA（同屏可见，不滚动就能点）
  02 可信证明：评价 / 数据 / 客户 logo / 媒体提及
  03 说明：3 个"为什么是我"（不是功能罗列，是差异化）
  04  objections：FAQ / 退款 / 风险消除
  05 重复 CTA（与 01 同一动作，同一样式）
  06 页脚兜底 CTA
```
**整页只服务一个动作。** 出现第二个并列 CTA 就是设计失败。

### 双渠道（线上 + 线下）

同时有线上购买和线下门店时，**两个动作不是等权的**：
- 能远程成交、可度量、可承接陌生流量的那个 → **主 CTA**（通常是线上）
- 另一个 → **降级为信息**，放页脚前的弱化区块，只给地址/时间，不给并列按钮

判据：哪个动作能服务绝大多数访客？线下店只能服务本地，线上能服务全部流量，故线上为主。

### 卖实物商品时

在页脚前追加**合规信息区块**（品名/配料/净含量/保质期/贮存/生产者/SC/过敏原），完整展开，不折叠、不小字。它是法规要求，同时也是这个品类最有效的信任来源——食品站把配料表写清楚，比放十条好评管用。

## 典型误用
- **无转化目标时套这个三段式**——最常见的错误。hero 后面接社会证明，但用户压根不需要被转化，页面会显得空洞且吵。
- CTA 用低对比色 → 转化站唯一不能让步的是 CTA 对比度
- 把"关于我们"塞进 02 → 打断说服链

## Token 倾向
- CTA 与主色对比度必须 ≥ 4.5:1，且是全页唯一的强色块
- 句子短（≤15 字一个意群），段落 ≤3 行
- 分区用背景微差而非分割线，保持滚动连续
- 动效只服务于"指出 CTA"，不做装饰

## 被排除的常见原因
转化目标答"无" → 直接排除。这是唯一一条硬排除，不打折。

## 页面粒度与页内导航（默认，可被内容推翻）

> 阈值与完整判据见 [`granularity.md`](granularity.md)。这里只给本原型的默认倾向。

- **默认粒度**：`single` —— 整页只服务一个动作，拆页等于稀释转化
- **默认页内导航**：`none` —— **转化页的区块是「说服链」的一环，给整页目录 = 请用户跳离说服链**
- **唯一的升档理由**：页面里出现**查阅型区块**（FAQ / 规格表 / 合规信息）→ 升为 `anchor-jump`，
  且**锚点只指向那些区块**（用户对它们是「来查」而不是「来读」），不给整页目录
- 区块 ≥7 的长转化页（多轮证明 + FAQ + 合规）同样升为 `anchor-jump`
- 卖实物商品时这条最正当：**合规信息不可折叠、又必须完整** → 用户需要一条直达它的捷径。
  这也顺带满足了「合规信息要在页面上」的法规要求。
