# IA：叙事长页型（Narrative）

**核心命题**："听我讲一件事。"

## 适用条件
- 有一个**线性的、值得被讲的故事**（品牌缘起、项目过程、时间线）
- 内容量小但深：不需要检索，需要被读
- 受众耐心高（深度阅读者、评审、被推荐来的）
- **视觉资产质量低时的首选**——靠文字和排版撑，不靠图

## 区块组成
```
单页长滚动：
  01 开场主张（一句话，不是 slogan，是主张）
  02 缘起 / 问题
  03 过程 / 材料 / 方法
  04 结果与现状
  05 如何找到我 / 下一步
```
章节用编号锚定（`01 / 02 / 03`），既是导航也是节奏。不要做侧边进度条之外的花活。

## 典型误用
- 内容其实有 50 条 → 长滚动会变成信息坟场，改走 directory
- 每屏都塞满 → 叙事需要留白节奏，密度一高就失去叙事性
- 入场动效过多 → 用户滚动三次就烦了。**每个章节最多一个动效，且不要阻塞阅读**

## Token 倾向
- 章节间距极大（≥120px），章节内紧凑
- 字阶跨度大：主张级 vs 正文级至少 3 倍
- 每屏最多 2 个色块，其余是纸色
- 章节编号用等宽或小写罗马，作为视觉锚点

## 被排除的常见原因
受众耐心低（路人与回头客）→ 长滚动无人读完；转化目标明确 → 改走 conversion。

## 页面粒度与页内导航（默认，可被内容推翻）

> 阈值与完整判据见 [`granularity.md`](granularity.md)。这里只给本原型的默认倾向。

- **默认粒度**：`single` —— 长滚动就是它的形态，拆页会毁掉叙事
- **默认页内导航**：`anchor-jump` —— 章节锚点
  - 章节 <4 → 降为 `none`（没有可跳的目标）
  - 章节 ≥8 → 升为 `sticky-toc`
- **章节编号（`01 / 02 / 03`）本身就是导航锚点。** 做了编号却没做成可点的锚点 = 半成品；
  编号只当装饰用，读者仍然只能一翻到底。
- 例外：内容其实是 50 条并列条目 → 不是叙事，改走 directory 或 `master-detail`。
